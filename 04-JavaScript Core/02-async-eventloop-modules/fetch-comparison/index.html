Bài học rút ra từ thực tế:

      
    
        
  • Dùng Promise.all: Khi các request độc lập dữ liệu (ví dụ: lấy song song Profile, Notification, và Cart). Tốc độ tăng gấp nhiều lần so với tuần tự.
    • 
        
  • Dùng Promise.allSettled: Khi muốn hoàn thành tất cả request dù có 1 vài request phụ bị lỗi.
    • 
        
  • Dùng Vòng for + await: Khi request thứ 2 cần dữ liệu từ request thứ 1, hoặc khi cần hạn chế tải lên server.
