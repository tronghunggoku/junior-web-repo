Bài tập 01: Git Workflows

Thực Hành Git & Quy Trình Pull Request Chuẩn Doanh Nghiệp

Xây dựng lịch sử commit nguyên tử (Atomic Commits), thực hành Git Flow, quản lý nhánh và tự gỡ Merge Conflict chuyên nghiệp.

Xem Kỹ Năng Đọc Tài Liệu

Kỹ Năng Git Cần Đạt (Rubric)

1. Atomic Commits

Chia nhỏ các câu lệnh `git commit` thành từng đơn vị chức năng duy nhất, tuân thủ Conventional Commits.

2. Git Flow & PR

Tạo nhánh feature chuẩn xác, đẩy PR lên remote với mô tả đầy đủ ngữ cảnh và checklist.

3. Conflict Resolution

Tự tay rebase/merge và resolve xung đột code mà không làm mất dòng code quan trọng nào.

Bảng Tra Cứu Câu Lệnh Git Thiết Yếu

# 1. Khởi tạo & kiểm tra
git init
git status
git log --oneline --graph

# 2. Tạo nhánh & chuyển nhánh
git checkout -b feature/tinh-nang-moi
git switch main

# 3. Commit theo quy chuẩn
git add .
git commit -m "feat(scope): mo ta ngan gon"

# 4. Dong bo & Rebase gỡ conflict
git fetch origin
git rebase main
git push --force-with-lease origin feature/tinh-nang-moi
