# Bài Tập 01: Quy Trình Git Workflows & PR End-to-End

Thư mục này chứa bài tập thực hành Quy trình Git chuyên nghiệp, bao gồm việc tạo commit chuẩn, tạo Pull Request (PR), xử lý phản hồi từ Mentor, và tự gỡ Merge Conflict.

---

## 🎯 Mục Tiêu Bài Tập
1. **Commit History Sạch:** Thực hiện ≥ 5 commits nguyên tử (Atomic Commits) tuân thủ quy chuẩn **Conventional Commits**.
2. **Quy trình PR End-to-End:** 
   - Khởi tạo nhánh `feature/contact-and-feedback`.
   - Viết mô tả PR chuyên nghiệp (PR Template).
   - Tự tay giải quyết **Merge Conflict** với nhánh `main`.
   - Cập nhật code theo feedback của Mentor.
   - Merge PR và dọn dẹp nhánh feature.

---

## 📋 Rubric Đánh Giá
- ✅ **Thao tác Git:** Thành thạo add, commit, branch, merge, rebase.
- ✅ **Commit & Lịch sử:** Lịch sử nguyên tử, rõ ràng, sạch đẹp.
- ✅ **Xử lý Conflict:** Tự gỡ conflict gọn gàng, giữ nguyên tính toàn vẹn của code.
- ✅ **Pull Request:** Đúng quy chuẩn, tự review trước khi gửi.
