Kỹ Năng Kỹ Thuật

Các công nghệ cốt lõi tôi áp dụng để xây dựng giao diện web chuẩn mực.

    Cấu trúc tài liệu chuẩn WCAG, a11y landmarks, SEO metadata, tối ưu cấu trúc DOM không dùng div thừa.

    Cú pháp ES6+, xử lý bất đồng bộ, thao tác DOM API thuần, clean code và tư duy thuật toán.

    Thiết kế tương thích đa thiết bị theo tư duy Mobile-First, tối ưu kích thước tài nguyên và hiệu năng hiển thị.
