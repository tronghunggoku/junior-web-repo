Portfolio Giới Thiệu Bản Thân

Xây dựng khung HTML ngữ nghĩa chuẩn 100% không lạm dụng thẻ <div>. Tối ưu khả năng tiếp cận (a11y) và chỉ số chuẩn SEO cho công cụ tìm kiếm.

  • Sử dụng triệt để <main>, <section>, <article>
  • Ảnh đại diện ngữ nghĩa với <figure> & <figcaption>
  • Sidebar thông tin bổ trợ với thẻ <aside>
  • Thông tin liên hệ đạt chuẩn với <address>
  • Mốc thời gian chuẩn máy đọc với <time datetime="...">

Pricing Section Chuẩn BEM

Dựng bảng giá dịch vụ hiện đại kết hợp CSS Grid đa tầng và Flexbox định vị nút CTA. Đặt tên class theo phương pháp luận BEM và micro-interactions hover mượt mà.

  • 100% tuân thủ cấu trúc class Block__Element--Modifier
  • Bố cục CSS Grid responsive 3 cột tự động co giãn
  • Flexbox căn lề nút bấm thẳng hàng hoàn hảo
  • Hiệu ứng hover nâng card và viền sáng mượt mà
  • Bộ chuyển đổi chu kỳ thanh toán Tháng / Năm mượt mà
