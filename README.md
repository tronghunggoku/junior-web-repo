## 🛠️ Quy chuẩn Workflow
- **Git Flow:** `main` (production-ready code), `feature/*` (nhánh phát triển tính năng).
- **Commit Messages:** Theo chuẩn [Conventional Commits](https://www.conventionalcommits.org/).
- **Pull Requests:** Mỗi tính năng được tạo PR độc lập, tự review và resolve conflict trước khi merge.
